## 🛠️ Stack

- **Marcado:** HTML5 semántico, iconos SVG inline
- **Estilos:** CSS propio, sin framework · fuente Inter (Google Fonts)
- **Interacción:** JavaScript vanilla, sin build ni dependencias
- **Deploy:** GitHub Pages · GitHub

---

## 🚀 Empezar

No necesita instalación. Clona el repositorio y abre el archivo:

```bash
git clone https://github.com/DanielLerma12/Portfolio.git
cd Portfolio
# abre index.html en el navegador, o sirve la carpeta:
npx serve .
```
